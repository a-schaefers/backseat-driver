# Backseat Driver

A coding tutor inside Claude Code that never writes your code. You write every line. Type `/backseat` and a pane opens beside the conversation: play-by-play commentary on each save, every issue in your code ranked worst first from an audit and a review of each commit, an explanation of the code you point at, a level and growth score per language, and learning paths you work through in your own code. Claude stays in chat as a tutor: hints and explanations, never patches. While it's on, a hook blocks Claude's editing tools. `/backseat off` gives you Claude Code back, and `/backseat help` lists every command.

Needs Claude Code 2.1.287 or newer, git, and a Claude plan. Free for personal use; commercial use needs a license. More at https://github.com/a-schaefers/backseat-driver.
